Bank setup (administrator only)

This screen is only for the person setting up the bank. It connects SitBank to Supabase once. If someone sent you this to join, don’t fill this in — ask them for the ready-to-use SitBank file or link instead.

Run sitbank-schema.sql in the Supabase SQL Editor, then follow SETUP.md. To share the bank with your group, put these two values in the config block at the top of SitBank.html before sending the file — participants will open it and see only the name screen. Never paste the service-role key here.
